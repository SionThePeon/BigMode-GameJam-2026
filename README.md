# FrostBite Delivery
*Made for BigMode Game Jam 2026 — 9 days (January 29th – February 7th)*

A PS1/PS2-style game where you play as a pizza delivery man on his first day on the job. 
Face icy roads and upgrade your car to deliver all the way to the castle in the mountains.

---

## Gameplay
Deliver pizzas to earn money, then spend it on car upgrades between runs. 
Better upgrades let you drive further, handle worse conditions, and take on more deliveries.

---

## Code Navigation
All scripts are located in `BigMode 2026/BigMode2026/Assets/Script/`

| Script | Description |
|---|---|
| `carController.cs` | Logic behind how the car drives |
| `menuController.cs` | Logic for the upgrade system |
| `zoneScript.cs` | Logic for the reward system and how you earn money |
