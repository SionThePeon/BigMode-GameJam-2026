FrostBite-Delivery
Made for BigMode Game Jam 2026 — Had 9 days (January 29th to February 7th)
-Plays as a game reminecent of old ps1/ps2 games where you play as a pizza delivery man on this first day on the job. 
You must face the icey roads and upgrade your car to deliver to the castle in the mountains. 

Gameplay
Player must deliver pizza's to earn money - with that money they can purchase upgrades for their car that will allow them in the next run to deliver more pizza's, drive further, and etc.
Code Navigation
All scripts are located in the Scripts/ folder (BigMode 2026/BigMode2026/Assets/Script). Key files to check out:
carController.cs / Logic behind how the car drives
menuController.cs / Logic for the upgrade system
zoneScript.cs / Logic for the reward system and how you make money

Built With
Unity
3D modeling done in blender
2D pixel art done in asperite
